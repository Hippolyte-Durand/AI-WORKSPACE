# 🤖 Agents

**Définitions agents, orchestrations, configurations agents**.

## Convention

- **Type** : `agent`
- **Frontmatter** : `nom`, `projet: "[[slug]]"` (si spécifique) ou `related: [...]` (si générique)
- **Naming** : `Nom-Agent.md`

## Quand créer

- Agent custom définition/config
- Orchestration agents multi-projet
- Skill, hook, workflow agents
